# 🤖 Agente Calculadora ReAct desde Cero

Un agente de Inteligencia Artificial construido en **Python puro** utilizando el patrón de diseño **ReAct** (Reasoning + Acting) y **Function Calling** sin depender de frameworks complejos como LangChain o CrewAI.

## 📌 Características
- **Razonamiento Autónomo:** El modelo determina cuándo necesita usar una herramienta externa.
- **Ejecución Precisa:** Realiza cálculos mediante código nativo de Python para evitar alucinaciones matemáticas.
- **Seguridad:** Manejo de credenciales mediante variables de entorno (`.env`).

## 🚀 Requisitos Previos
- Python 3.10+
- Una API Key de Groq (o cualquier proveedor compatible con la API de OpenAI)
